# Skills — S.A.M.S. Business Intelligence Research & Analysis Agent

## Pipeline (set up -> build -> run -> optimise)
1. Market/offer research + positioning
2. Competitor campaign teardown (top-3 -> win factor + gap)
3. Offer, funnel and channel-mix design
4. Copy: ads, landing pages, VSL, email sequences, SMS, blogs, video scripts
5. Launch + distribution (social, email, SMS)
6. **A/B variance analytics** — significance, sample size, sequential testing
7. Live optimisation from campaign data
8. Reporting with sourced evidence
